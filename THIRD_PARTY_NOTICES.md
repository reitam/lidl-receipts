# Harmadik féltől származó komponensek

Ez a projekt az alábbi nyílt forráskódú csomagokat használja futásidőben.
A teljes licencszövegek a csomagokban, illetve azok forrásrepóiban találhatók.

| Komponens | Licenc |
|---|---|
| [requests](https://requests.readthedocs.io/) | Apache-2.0 |
| [Playwright (Python)](https://playwright.dev/python/) | Apache-2.0 |
| [qrcode](https://github.com/lincolnloop/python-qrcode) | BSD |
| [python-barcode](https://github.com/WhyNotHugo/python-barcode) | MIT |
| [openpyxl](https://openpyxl.readthedocs.io/) | MIT |
| [FastAPI](https://fastapi.tiangolo.com/) | MIT |
| [Uvicorn](https://www.uvicorn.org/) | BSD-3-Clause |
| [Jinja2](https://jinja.palletsprojects.com/) | BSD-3-Clause |
| [python-multipart](https://github.com/Kludex/python-multipart) | Apache-2.0 |
| [Pillow](https://python-pillow.org/) | MIT-CMU |
| [httpx](https://www.python-httpx.org/) (csak tesztekhez) | BSD-3-Clause |
| [Python](https://www.python.org/) | PSF-2.0 |

A Docker image ezeken felül tartalmazza:

- **Chromium** (Playwright) – BSD-3-Clause és további nyílt forráskódú
  licencek; a részletes lista a Chromium forrásfájában található.
- **Liberation fonts** – SIL Open Font License 1.1.
- **DejaVu fonts** – Bitstream Vera Fonts License.
- Debian alapú rendszerkomponensek – a Debian licencei szerint.

A Lidl, a Lidl Plus és a hozzájuk tartozó logók a Lidl védjegyei. Ez a
projekt nem áll kapcsolatban a Lidllel, és nem a Lidl hivatalos eszköze.
